# Практическая работа №5 - проекты Ramus

Два самостоятельных проекта ООО «ТехноСервис» в родном формате `.rsf`:

| Проект | Файл |
|---|---|
| Аренда виртуальных серверов | [УИТУ5_Аренда_ВМ_ТехноСервис.rsf](УИТУ5_Аренда_ВМ_ТехноСервис.rsf) |
| Мониторинг и поддержка систем | [УИТУ5_Мониторинг_ТехноСервис.rsf](УИТУ5_Мониторинг_ТехноСервис.rsf) |

Скачайте файл через **Download raw file** на GitHub, затем в Ramus выберите
**Файл → Открыть** или нажмите **Ctrl+O**. Для перехода к декомпозиции выберите
функцию в дереве модели или откройте её двойным щелчком на диаграмме.

В каждом проекте шесть листов:

- `A-0`: контекст с одной функцией `A0` и отдельными стрелками ICOM;
- `A0`: первый уровень, четыре функции `A1`, `A2`, `A3`, `A4`;
- `A1`, `A2`, `A3`, `A4`: второй уровень, по три дочерние функции.

Всего в каждом файле 17 функций. Блоки, стрелки, развилки, подписи и связи
между уровнями редактируются в Ramus. Имена функций, входы, выходы, управления
и механизмы соответствуют отчёту №5. Авторы, компания и проект указаны в штампе.

В папке `previews` находятся изображения всех листов, экспортированные самим
движком Ramus Next 3.1.1. Результаты открытия, чтения и отрисовки сохранены в
[ramus-validation.json](../../evidence/ramus-validation.json).

## Повторная сборка

Используется библиотека формата
[ramus-mcp](https://github.com/byMERCY/ramus-mcp), лицензия MIT, с фиксированной
ревизией. Нужны Python 3.12+ и Pillow из `requirements-docs.txt`.

```bash
git clone https://github.com/byMERCY/ramus-mcp.git /tmp/uitu-ramus-writer
git -C /tmp/uitu-ramus-writer checkout a311ca2fcbc5aceb2f56d2b026ff26a6c83a0164
python tools/ramus_files.py --writer-src /tmp/uitu-ramus-writer
```

Команды выполняются из корня репозитория. Генератор читает те же исходные
модели `tools/diagrams.py`, что использованы для отчёта, и проверяет дерево,
ICOM, маршруты стрелок и балансировку между уровнями.

Для независимой проверки установленным движком Ramus Next:

```bash
python tools/validate_ramus_engine.py --engine-jar /path/to/ramus.jar
python tools/package_deliverables.py
```

`ramus.jar` - официальный JAR приложения Ramus Next 3.1.1. Проверка работает
на временных копиях файлов в режиме чтения и экспортирует все 12 диаграмм.
